**Synchronous FIFO Memory Design using Verilog HDL**

Designed a 4-depth, 8-bit synchronous FIFO memory using Verilog HDL. Implemented read and write pointer management, data storage, occupancy counter, and full/empty flag generation. Prevented invalid read and write operations using status-based control logic. Verified FIFO functionality through Verilog testbench simulation using ModelSim.
